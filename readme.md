# Russel's Art Portfolio

## Overview
A personal portfolio website for presenting my artwork and sharing information about me.

## Features
- The navigation menu that can be shown or hidden in every webpage size.
- The light and dark theme switches properly
- Artwork cards generated from JavaScript data is visible properly for visitors to see.
- Contact form validation with field-specific messages as required by my professor.

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage

## Setup
1. Open the project folder in Visual Studio Code.
2. Open `index.html` with Live Server.
3. Use the navigation menu to visit the other pages.
